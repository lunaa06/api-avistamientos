# API REST de Avistamientos de Aves

## Descripción

Se creo una API REST el cual permite registrar y consultar avistamientos de aves, donde cada avistamiento contiene:

- ID
- Especie
- Lugar
- Fecha
- Observador

El proyecto fue desarrollado utilizando Python, Flask y SQLite.

## Tecnologías utilizadas

- Python
- Flask
- SQLite
- JSON
- REST API
